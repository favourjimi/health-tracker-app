# Health Tracker App

## 📌 Project Overview

This is a full-stack Health Tracker application that allows users to log and monitor daily health activities such as water intake, sleep hours, and steps.

---

## 🧱 Tech Stack

* Frontend: React (to be implemented)
* Backend: Node.js, Express
* Database: MongoDB (Atlas)
* Version Control: Git & GitHub

---

## ⚙️ Current Progress

* Backend server setup ✅

## 👥 Team Responsibilities

### 🔹 Backend (Favour)

* Setup Express server
* Connect MongoDB
* Build API routes:

  * POST /api/entries
  * GET /api/entries

### 🔹 Frontend (Teammate)

* Setup React app
* Build UI:

  * Input form (water, sleep, steps)
  * Display entries

## 🔗 API Endpoints (Planned)

### POST /api/entries

Add a new health entry

### GET /api/entries
